# دعوة زفاف مؤمن ورقية

دعوة زفاف عربية تفاعلية، مصممة بتقنية HTML وCSS وJavaScript فقط.

## التشغيل

يفضل تشغيل المشروع عبر أي خادم ملفات محلي يدعم Vite حتى تعمل وحدات JavaScript بشكل صحيح. يمكن أيضاً نشره على أي استضافة ثابتة.

## التخصيص

جميع الإعدادات الأساسية موجودة في أعلى `src/main.ts` داخل الكائن `CONFIG`:

- أسماء العروسين وتاريخ ووقت الحفل
- اسم القاعة والعنوان
- رابط خرائط Google
- رقم WhatsApp
- مسار ملف الموسيقى
- صور الغلاف والتفاصيل

أضف ملف الموسيقى في `public/assets/audio/wedding-music.mp3`، ثم حدّث الروابط المطلوبة داخل `CONFIG`. يمكن فتح دعوة مخصصة باستخدام `?name=اسم-الضيف`.

## ملاحظات

- الموسيقى لا تعمل تلقائياً، وتبدأ عند ضغط زر الموسيقى.
- إذا لم يتم وضع رابط الخرائط أو رقم WhatsApp، ستظهر رسالة إرشادية بدلاً من فتح إعداد غير مكتمل.
- الصور الحالية صور تجريبية خارجية ويمكن استبدالها بروابط صور الزفاف الخاصة بك.
